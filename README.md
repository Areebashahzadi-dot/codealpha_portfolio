# Areeba Shahzadi — Personal Portfolio
Responsive portfolio made with HTML, CSS and JavaScript.

## Included
- About, skills, projects, resume and contact sections
- Four project cards: Image Gallery, Calculator, Portfolio, Touchless Mouse Controller (in progress)
- Responsive mobile navigation, smooth scrolling, reveal animations and hover effects
- Updated pastel PDF resume; View Resume opens the PDF in a new browser tab, while Download Resume downloads it
- Contact form that opens the visitor's email app using `mailto:`

## Run
Extract the ZIP and open `index.html` in a browser.

## Before publishing
- Your GitHub profile is connected: https://github.com/Areebashahzadi-dot. Add your LinkedIn URL in `script.js` (`profileLinks`) when available.
- Upload each project to its own GitHub repository and replace each “Add GitHub link” placeholder in `index.html` with the correct repository URL.
- Verify the email address.
- A public GitHub Pages or Netlify site can be viewed by anyone. Only publish contact details you are comfortable sharing publicly.

## GitHub Pages deployment
1. Create a repository, e.g. `areeba-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `Areeba_Shahzadi_Resume.pdf` and `README.md` to its root.
3. Go to repository Settings → Pages.
4. Select “Deploy from a branch”, choose `main` and `/ (root)`, then Save.
5. Open the public Pages URL GitHub provides.

## Resume buttons
- View Resume opens the PDF in a separate browser tab (it is not embedded below the section).
- Download Resume saves the PDF to the visitor's device.

## Contact form limitation
The form prepares an email in the visitor's default mail app. It does not send automatically or store submissions. A backend or form service is needed for a fully hosted contact form.
